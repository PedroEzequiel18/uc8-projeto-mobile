# UC8 Projeto Mobile

Aplicativo mobile da UC8 baseado no sistema Gestor de Fluxo de Caixa desenvolvido na UC5.

## Sistema de origem

O sistema Gestor de Fluxo de Caixa permite o controle de receitas e despesas por meio do cadastro de categorias e transações financeiras.

## Entidades

### Categoria

- id
- nome
- tipo

### Transacao

- id
- nome
- descricao
- valor
- id_categoria
- data

## Telas previstas

1. Dashboard financeiro
2. Listagem de transações
3. Cadastro de transação
4. Edição de transação
5. Listagem de categorias

## Fora do escopo

- Integração bancária
- Relatórios avançados
- Exportação de dados
- Controle de múltiplos usuários
- Recuperação de senha
